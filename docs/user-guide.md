# 用户指南

本文件按日常使用顺序说明 LexiGrab：首次启动、添加词典、划词查询、选择义项、编辑保存、扩展配对与失败恢复。字段含义与默认值见 [configuration.md](configuration.md)，扩展安装与错误码见 [extension.md](extension.md)，排查细节见 [troubleshooting.md](troubleshooting.md)。

## 1. 首次启动

首次启动时，应用会：

1. 在用户配置目录创建 `config.toml`、设备 ID 和 64 位十六进制桥接令牌。
2. 打开管理器，并显示三步引导：添加词典、配置 Anki、设置热键。
3. 已完成的步骤会即时打勾；全部完成或关闭引导后，引导收起到“运行状态”。

可以跳过任何一步：

- 没有 `.mdx` 文件时先跳过；划词查不到结果时，弹窗会提供“添加词典”入口。
- Anki 未运行时先跳过；保存卡片时再提示安装或启动。
- 热键冲突时必须换一个组合键，或保留默认并处理冲突。

应用常驻托盘。关闭管理器或设置窗口只是隐藏窗口，进程不会退出；退出请使用托盘菜单。

## 2. 添加本地词典

1. 打开管理器，进入“词典源”，点击“添加源”。
2. 选择“本地词典”，点击“选择 .mdx 文件”，可以一次选择多个文件。
3. 输入源名称；默认使用第一个文件名。
4. 保存后，源会在后台加载，状态从“正在加载”变为条目数。

规则：

- 同一个源里的多个 `.mdx` 会合并展示；同名 `.mdd` 放在同一个目录即可自动加载图片和音频。
- 同一路径不能出现在多个源中；管理器会指出冲突的源名称。
- 源可以启用、禁用、重命名、上移或下移；调整顺序会重写优先级。
- 删除源只删除配置，不删除磁盘上的词典文件。
- 大词典在后台打开，不阻塞窗口；加载失败时行内显示错误摘要和“重试”。

远程词典在同一个对话框里选择“远程 API”，填写 URL 模板、鉴权头、超时与 JSONPath 或脚本。具体字段见 [configuration.md](configuration.md)。启用远程词典后，查询词会发送到该服务；脚本解析在本地沙箱中执行，但沙箱不是强隔离，只应运行可信脚本。

## 3. 划词查询

1. 在记事本、浏览器、IDE 或其他应用里选中一个词。
2. 按全局快捷键，默认 `Ctrl+Shift+D`。
3. 弹窗出现在选区附近，快速模式不抢原应用焦点。
4. 本地结果先显示；远程结果到达后追加，底部显示远程进度。
5. 再次按快捷键或点击关闭，弹窗隐藏并恢复触发前的前台窗口。

如果没有捕获到文本，弹窗进入错误态，可以重试或手动输入单词。没有结果时仍可“仍然制卡”或打开词典管理；远程源失败只显示提示，不影响本地结果。

## 4. 义项、推荐与 AI

弹窗会保留词典返回的全部义项，推荐只做高亮和排序，不删除其他义项。

| 情况 | 界面 | 保存行为 |
| --- | --- | --- |
| 高置信度 | 高亮推荐义项，显示置信度与模型名 | 保存默认使用推荐义项 |
| 中置信度 | 高亮并显示“建议确认” | 不自动改变选择，由用户确认 |
| 低置信度或无匹配 | 显示“可能不在词典义项中” | 保留全部义项；可手动选择，或使用 AI 释义 |
| 选择器不可用或超时 | 辅助区提示 | 不自动调用 LLM，词典结果与保存按钮仍可用 |

没有原句时不做自动选择，也不自动调用 LLM。置信度是模型自评，不是准确率，界面不会把它显示成客观概率。

AI 释义：

- 只有启用 LLM 且出现低置信度时才生成。
- 卡片会显示“AI 生成”、模型名和“可能不准确”，默认不选中。
- 点击“使用此释义”后，AI 文本进入编辑区的释义字段，仍可修改。
- AI 结果是生成内容，不是词典原文，不能当作词典事实。
- 采用 AI 释义保存时，来源写作 `AI · <模型>`，并追加 `ai-generated` 标签。

用户手动切换义项或选择 AI 释义后，以用户选择为准，迟到的推荐不会覆盖。

## 5. 编辑与保存

点击“编辑”进入编辑模式，窗口会获得键盘焦点：

- 释义有“原文”和“源码”两个 tab；源码可编辑 HTML，预览实时刷新。
- 原句可以编辑，也可以留空。
- 单词和来源只读。
- `Ctrl+Enter` 保存，`Esc` 取消。
- 保存失败会保留全部输入并显示错误。

保存结果：

| 结果 | 界面 | 后续 |
| --- | --- | --- |
| 成功 | 显示 note id 与“已保存” | 弹窗不自动关闭，可“再存一张”或关闭 |
| 同词同句同释义已存 | 提示该语境已保存过 | 可以“仍然保存”，也可以换义项或改原句 |
| Anki 未运行 | 显示安装/启动指引 | 留在弹窗，可重试 |
| 字段缺失 | 指明缺失字段 | 打开 Anki 设置修正映射 |
| 其他错误 | 通用错误与可复制信息 | 修改后重试 |

保存前会校验模板的四个字段。只有“同词 + 规范化原句 + 规范化释义”完全相同时才提示重复；不同原句或不同义项不会提示。

## 6. 同词多卡

同词多卡是默认行为，不需要额外开关：

- 同一单词在不同句子下可以连续保存多张卡。
- 同一单词、同一句子、不同义项或释义也可以分别保存。
- Anki 请求始终允许重复；应用层只对“同词同句同释义”提示一次。
- 提示出现后可以直接“仍然保存”，不会阻断写入。
- 设置里的 `duplicate_policy` 只控制提示或静默保存，不控制允许或禁止重复。

保存成功后弹窗保持打开，可以换一个义项再存一张。

## 7. 设置六个分区

设置窗口左侧有六个分区。保存按钮固定在分区底部；有未保存更改时会提示。

### 通用

- 全局热键：录制组合键后保存。后端先尝试注册新热键，成功才写盘；冲突时恢复旧热键并提示，不写配置。
- 主题：`figma`、`apple`、`cursor` 三选一，切换立即预览，保存后持久化。0.1.0 没有深色主题。
- 查询策略：`local_first`（本地优先）、`first_hit`（首个命中）、`aggregate`（聚合全部）。
- 每源条数与总条数：默认 3 和 20，分别限制 1–10、5–50。
- 启动行为：是否最小化启动。保存后下次启动生效。

### Anki

- 进入分区时异步探测 AnkiConnect；不可用时显示安装/启动三步引导，不影响其他设置。
- 填写 endpoint，测试连接；成功后选择牌组与笔记类型。
- 选择模板后刷新字段下拉框，再配置四个字段映射。
- 保存前校验映射非空；已连接 Anki 时校验字段存在于模板；导出前还会校验字段存在且映射不重复。
- 标签、同语境重复策略与连接状态在同一分区。
- “测试连接”只读，不写测试卡片。

### 语境辅助

- 选择器开关：关闭时只展示全部义项。
- 选择器地址与超时：默认 `http://127.0.0.1:8787/v1/select` 和 800ms，只允许回环地址；远程地址需要勾选“允许远程选择器”。
- 低/高置信度阈值：默认 0.55 / 0.72，必须满足 `0 < 低 < 高 ≤ 1`。
- LLM：开关、OpenAI-compatible 地址、模型名、超时、最大 token、API key 环境变量名。
- 默认只允许回环 LLM；勾选“允许远程 LLM”会提示原句与候选义项将发送到该服务。
- “测试选择器”和“测试 LLM”使用已保存配置，不写缓存、不写卡片。修改设置后先保存再测试。
- 语境缓存可以单独清理。选择器与 LLM 的失败只影响辅助区，不影响词典结果。

### 浏览器扩展

- 显示启用开关、端口、运行状态、最近请求时间。
- 令牌默认遮罩，可显示、复制。
- “重新生成令牌”需要二次确认；轮换后旧令牌立即失效，扩展要重新配对。
- 端口保存后重启桥接。端口被占用时保存的配置保留，但桥接状态显示错误；换一个端口再保存。
- 配对步骤共三步：复制令牌、填入扩展、测试连接。

### 缓存

- 显示条目数、占用与 TTL。
- 修改 TTL 只影响新写入；已有条目按原过期时间。
- “清除词典缓存”需要二次确认，不删除已保存卡片历史，也不清除语境缓存。
- “清除语境缓存”使用独立入口，清理后下次查询会重新请求选择器或 LLM。

### 关于

- 显示版本、构建信息、配置目录、日志目录和缓存文件路径。
- 可以复制或打开配置、日志、缓存目录；重新打开首次引导。
- 可以打开许可证与仓库链接。第三方依赖与许可证清单见仓库文档。

## 8. 扩展配对与划词

1. 桌面端“设置 → 浏览器扩展”，确认已启用，复制端口（默认 12787）与令牌。
2. 在 Firefox 安装扩展。首次安装会自动打开扩展设置页。
3. 填入端口与令牌，点击“测试连接”；成功后保存。
4. 回到网页，选中文本，点击选区旁的浮动按钮。
5. 气泡显示释义、原句与来源；可以切换条目并保存。
6. 保存成功后按钮变为“已保存”，并提供“再存一张”。

边界：

- 扩展在 iframe 内不支持划词。
- 气泡里的原句只读，编辑在桌面端完成。
- 扩展会显示语境建议与 AI 释义，但保存仍使用所选词典义项，不能采用 AI 释义。
- 扩展不直接访问 AnkiConnect、远程词典、选择器或 LLM。
- 同一单词可以连续保存多张；同语境重复只提示，不阻断。

扩展安装、未签名限制与错误码见 [extension.md](extension.md)。

## 9. 常见失败恢复

| 现象 | 先做什么 |
| --- | --- |
| 按热键没有弹窗 | 确认应用在托盘运行；在设置里重新录制热键；检查是否与其他软件冲突 |
| 提示没有捕获到文本 | 先在目标应用里重新选中文本，或使用弹窗里的手动输入 |
| 查询没有结果 | 查看词典源状态；确认源已启用、路径有效；用查询测试定位是源还是查询问题 |
| 图片不显示 | 确认 `.mdd` 与 `.mdx` 同目录同名；检查词典状态与资源路径 |
| Anki 未运行 | 启动 Anki，确认 AnkiConnect 已安装，再点“测试连接” |
| 字段缺失 | 在 Anki 设置里刷新模板字段并重新映射四个字段 |
| 扩展提示未配对 | 从桌面端复制新令牌，在扩展设置里保存并测试 |
| 扩展令牌错误 | 桌面端可能轮换了令牌；重新复制并配对 |
| 桥接端口占用 | 在桌面端“浏览器扩展”分区换一个 1024–65535 的端口并保存，再在扩展设置里同步端口 |
| 远程词典失败 | 用源编辑里的测试查看原始响应；检查 URL 模板、鉴权、超时与解析表达式 |
| 语境推荐不可用 | 确认语境辅助已启用、有原句、选择器地址可访问；失败不影响词典结果 |
| AI 释义不可用 | 确认 LLM 已启用、模型名已填、API key 环境变量存在；远程端点需要显式允许 |
| 配置损坏 | 应用会备份为 `config.toml.bak-<时间戳>` 并以默认配置启动；恢复备份前先退出应用 |

更细的症状、原因和动作见 [troubleshooting.md](troubleshooting.md)。

## 10. 数据位置与退出

默认位置：

- 配置：`%APPDATA%\LexiGrab\config.toml`
- 缓存：`%LOCALAPPDATA%\LexiGrab\cache.db`
- 日志：`%LOCALAPPDATA%\LexiGrab\logs\`

设置 `LEXIGRAB_HOME` 或 `LEXIGRAB_CONFIG_DIR` 可以改变位置，规则见 [configuration.md](configuration.md)。所有数据保存在本机，不提供云同步；卸载应用不会自动删除用户目录里的配置、缓存和日志。
