# 故障排查

本文件按症状排查 LexiGrab 的常见问题。每条给出症状、原因和动作。界面只显示可读错误，原始堆栈只进日志；排查时也不要粘贴令牌、完整原句或 API key。字段与默认值见 [configuration.md](configuration.md)，扩展安装与错误码见 [extension.md](extension.md)。

## 1. 热键

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 按默认热键没有弹窗 | 应用未运行；热键被其他程序占用；注册失败 | 确认托盘里有 LexiGrab；在“设置 → 通用”重新录制一个含 Ctrl/Alt/Shift 的组合并保存 |
| 保存热键时提示冲突 | 新组合已被系统或其他应用注册 | 换一个组合；关闭占用该热键的程序后重试。保存失败时旧热键仍有效，配置不会写盘 |
| 启动后状态页显示热键错误 | 配置中的热键在当前系统不可用 | 打开设置重新录制；必要时改用 `Ctrl+Alt+字母` 一类组合 |
| 热键偶尔失效 | 目标应用抢焦点或系统级快捷键冲突 | 先点击目标窗口再试；确认没有输入法或自动化工具拦截 |

热键切换在先注册成功后写盘；失败不会留下半套配置。

## 2. 捕获

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 弹窗提示没有捕获到文本 | 触发时没有活动选区；选区在密码框或安全控件中；目标应用不暴露 UIA 文本 | 重新选中文本再按热键；用键盘 Shift + 方向键确认选区；改用弹窗中的手动输入 |
| 捕获到空词或半个词 | 选区包含多余空白或跨控件；目标应用渲染方式特殊 | 只选单词后重试；必要时手动输入 |
| 只在某些应用失败 | 应用以管理员权限运行，普通权限的 LexiGrab 读不到其 UIA；或应用自绘界面 | 不要为查词随意提权；优先手动输入或复制到记事本再划词 |
| 原句为空 | 桌面句子捕获是尽力而为，超时或 UIA 不提供段落 | 点击“编辑”手动补原句；网页场景优先使用 Firefox 扩展 |

捕获失败不会阻止手动输入和制卡。

## 3. MDX / MDD

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 源一直显示“正在加载” | 词典很大，打开超过预算；文件在网络盘或正在被占用 | 等待打开完成；把词典复制到本地磁盘；用查询测试确认是否可查 |
| 源状态为 failed | 文件损坏、截断、不是 MDX，或属于不支持的私有变体 | 查看行内错误摘要；用其他阅读器确认文件可打开；更换词典文件后重试 |
| 同一路径被拒绝 | 同一 `.mdx` 已经出现在另一个源 | 在冲突源里删除该路径，或合并到一个源 |
| 某些词查不到 | 词典本身没有该词；大小写或标点差异；MDX 变体不支持 | 换一个词测试；检查词典内容；不要期望覆盖全部私有格式 |
| 同名 `.mdd` 不生效 | `.mdd` 不在同目录，或文件名与 `.mdx` 不一致 | 把 `.mdd` 改成与 `.mdx` 同名并放在同目录；重新加载源 |

MDX worker 打开超时 15 秒、单次查询超时 500 毫秒；连续失败时该源进入错误状态，不影响其他源。

## 4. 图片与音频

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 释义里有破图 | 没有 `.mdd`；`.mdd` 名称或目录不匹配；资源路径大小写不一致 | 检查同目录同名 `.mdd`；重新添加源；用原词典软件确认资源存在 |
| 音频控件不可用 | 资源缺失，或音频格式不在允许的 MIME 白名单内 | 确认 `.mdd` 完整；更换词典或忽略该音频 |
| 本地图片在扩展气泡里只有占位文本 | 浏览器无法读取 `mdx-res` 本地资源 | 这是设计行为；在桌面端查看图片，扩展只保留文本与远程资源 |
| 远程图片不显示 | 词典内容引用了外网图片，网络不可达或被拦截 | 检查网络；远程图片属于词典内容，不影响文字释义 |
| 路径含 `..` 或异常编码 | 资源路径穿越被拒绝 | 更换词典文件；不要手工构造资源 URL |

## 5. Anki

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 提示 Anki 未运行或 AnkiConnect 未安装 | Anki 没启动；插件未安装；endpoint 不对 | 启动 Anki；安装 AnkiConnect（代码 `2055492159`）；在设置里点“测试连接” |
| 连接测试超时 | 端口被占用、endpoint 写错，或 Anki 正在启动 | 确认 endpoint 默认 `http://localhost:8765`；等待 Anki 启动完成后重试 |
| 字段缺失 | 模板改名或字段映射过期 | 在 Anki 设置里选择模板，刷新字段，重新映射 `Word/Definition/Sentence/Source` |
| 牌组或模板不存在 | 删除了牌组/模板，或名称大小写不一致 | 在 Anki 中创建对应牌组/模板，或在设置里重新选择 |
| 写入报 Anki API 错误 | AnkiConnect 拒绝请求，常见于字段类型、模板或超大 HTML | 检查模板与字段；缩短释义；查看桌面端日志中的错误摘要 |
| 保存成功但卡片没有媒体 | 本地媒体不会上传，只写 `[图片]`/`[音频]` 占位 | 这是 0.1.0 的契约；需要在 Anki 侧自行补充媒体 |
| 同词同句同释义提示 | 该语境已经保存过 | 可以“仍然保存”，或换义项/改原句；不同语境不会提示 |

“测试连接”是只读操作，不会写入测试卡片。

## 6. 扩展

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 提示还没有配对 | 扩展设置中没有令牌 | 桌面端复制令牌，填入扩展设置并保存 |
| 令牌错误（401） | 令牌被轮换；复制不完整；桌面端换了配置目录 | 重新复制当前令牌；确认端口一致；保存后测试连接 |
| 连接失败或离线 | 桌面端未启动；桥接被关闭；端口不一致 | 启动桌面端；在“设置 → 浏览器扩展”启用桥接；同步端口 |
| 来源被拒绝（403） | 请求不是从 Firefox 扩展发出 | 通过 Firefox 加载扩展后再划词，不要用普通网页请求桥接 |
| 扩展重启后消失 | 正式版使用临时加载 | 重新临时载入；或改用 Developer Edition / Nightly 的未签名安装路径 |
| 无法安装 `.xpi` | 正式版要求签名 | 使用临时加载；或按 [extension.md](extension.md) 的未签名路径操作 |
| iframe 内划词无反应 | 扩展不支持 iframe 内选区 | 在主页面选中文本，或复制到主页面再查 |

扩展只访问 `127.0.0.1`；不要把端口改成局域网地址。

## 7. 远程源

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 远程源超时 | 服务慢、网络不通，或超时设置过短 | 在源编辑里点测试；把超时调到 3000ms 左右；确认地址可从本机访问 |
| 远程返回 401/403 | 鉴权头或值不对；服务要求其他认证方式 | 检查 `auth_header`/`auth_value`；在测试里查看响应摘要；不要把密钥贴进日志 |
| 远程返回 500 或空结果 | 服务端错误；URL 模板或查询参数不对 | 确认模板恰好包含一个 `{word}`；用浏览器或 curl 验证原始响应 |
| 解析不出词条 | JSONPath 与响应结构不匹配；缺 `definition_html` 的条目被跳过 | 用测试查看前 4KB 原始响应；修正表达式；确认字段名 |
| 响应过大 | 响应体超过 2MB，或单条 HTML 超过 512KB | 缩小响应范围；让服务端返回精简字段；否则该源会失败 |
| 重定向后失败 | 跨主机重定向被停止，鉴权头不会随跨主机重定向发送 | 使用最终地址，或让服务端直接返回结果 |
| 远程失败影响本地结果 | 不应发生；远程失败只影响自身 | 若本地结果也被清空，记录操作步骤与日志，按缺陷处理 |

远程词典没有“允许远程”开关；只有选择器和 LLM 有回环限制。

## 8. 脚本解析

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 脚本返回无效数据 | 没有返回数组；条目缺 `headword`/`definition_html`；结构不是 Entry | 返回 `Entry[]`；每条至少包含 `headword` 和 `definition_html`；`source_name` 会被忽略 |
| `fetch is not defined` 或类似错误 | 沙箱没有 `fetch`、`XMLHttpRequest`、`require`、`process` 或定时器 | 只解析传入的 `responseBody`，不要发起网络请求 |
| 脚本超时 | 计算超过 200ms 默认预算 | 简化脚本；必要时把 `timeout_ms` 调到 50–1000ms |
| 脚本内存错误 | 处理了超大 JSON 或构造了过多对象 | 减少中间对象；只映射需要的字段 |
| 修改脚本后行为不变 | 源码按 mtime 缓存 | 保存文件并确认 mtime 更新；必要时重新加载源或重启应用 |

脚本是本地代码，沙箱不是强隔离。只运行可信脚本，不要从不可信来源复制解析脚本。

## 9. 语境选择器

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 没有推荐义项 | 语境辅助关闭；没有原句；候选义项为空 | 在设置打开语境辅助；编辑模式补原句；确认词典返回了义项 |
| 提示选择器不可用 | 地址不可达、超时，或返回结构不合法 | 在设置里“测试选择器”；确认地址与端口；检查服务是否返回 `selected_id` 与 0–1 置信度 |
| 远程选择器被拒绝 | 地址不是回环，且没有允许远程 | 使用 `127.0.0.1`，或显式勾选“允许远程选择器”并确认服务可信 |
| 推荐老是“建议确认” | 置信度落在低/高阈值之间 | 调整阈值，但不要把模型自评当成准确率；也可以手动选义项 |
| 推荐义项不对 | 模型判断错误，或词典义项切分过粗 | 手动切换义项；参考“可能不在词典义项中”的提示，不要盲信推荐 |
| 选择器失败后没有 AI 释义 | 设计上失败不会自动调用 LLM | 修正选择器；或手动点击使用 AI 释义（需已启用 LLM） |

选择器失败只影响辅助区，词典结果和保存按钮仍然可用。

## 10. LLM

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 低置信度但没有 AI 卡 | LLM 关闭；模型名为空；没有原句 | 在设置启用 LLM 并填写模型；补原句后重试 |
| 提示 `LLM_DISABLED` | 功能未启用 | 打开 LLM 开关并保存 |
| 提示 `LLM_REMOTE_BLOCKED` | 端点不是回环，且未允许远程 | 改用回环端点，或勾选“允许远程 LLM”并确认原句会发送到该服务 |
| 鉴权失败或没有响应 | API key 环境变量未设置；设置后没有重启 | 在启动应用前设置 `api_key_env` 指定的环境变量；重启应用；key 不写入配置 |
| 提示 `LLM_TIMEOUT` | 模型响应超过 15 秒默认超时 | 换更快的本地模型；把超时调到 1000–60000ms；检查服务负载 |
| 提示 `LLM_BAD_RESPONSE` | 模型没有返回要求的 JSON，或内容为空 | 换模型或调整提示；坏 JSON 会被丢弃，不会生成半截文本 |
| AI 释义不准确 | 生成内容本身可能错误 | 只把它当候选；核对词典义项后再决定是否采用 |

AI 释义不是词典原文；保存时来源写 `AI · <模型>`，并加 `ai-generated` 标签。

## 11. 同词多卡

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 同一单词保存时每次都提示重复 | 词、规范化原句、规范化释义完全相同；`duplicate_policy = warn` | 换义项、改原句，或点击“仍然保存”；需要静默时把策略改为 `allow` |
| 不同句子也被提示 | 不应发生；指纹包含原句 | 检查是否实际选中了同一句；若仍复现，记录步骤按缺陷处理 |
| 担心 Anki 侧拒绝重复 | Anki 请求始终 `allowDuplicate: true`，应用层不阻断不同语境 | 正常保存；同词同句同释义只是提示 |
| 保存成功但 Anki 里看起来重复 | 应用层按语境允许重复，不保证 Anki 历史完全一致 | 这是已知限制；需要严格去重时在 Anki 侧自行管理 |

同词多卡是默认行为：不同原句或不同义项本就应该可以分别建卡。

## 12. 缓存

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 远程结果一直是旧的 | 正结果默认缓存 24 小时 | 在“设置 → 缓存”清除词典缓存；或等待 TTL 过期 |
| 修改远程源后仍返回旧结果 | 旧缓存尚未过期；源修改未使缓存失效 | 清除词典缓存后重试；确认保存的是同一个源 |
| 空结果持续出现 | 负缓存默认 5 分钟 | 等待 5 分钟或清除词典缓存；检查远程服务 |
| 改了 TTL 但旧结果没变化 | TTL 只影响新写入，旧条目保留原过期时间 | 清除缓存，或等待旧条目过期 |
| 语境推荐不更新 | 语境缓存默认 168 小时 | 单独清除语境缓存；它和词典缓存分开 |
| 清除缓存后卡片历史还在 | 设计如此；`saved_cards` 不随词典缓存清空 | 这是正常的；历史用于同语境提示，不参与 Anki 去重 |

## 13. 配置损坏

| 症状 | 原因 | 动作 |
| --- | --- | --- |
| 启动后源列表为空、令牌变了 | 配置解析或校验失败，应用用默认配置启动 | 退出应用；在配置目录找 `config.toml.bak-<时间戳>`；确认备份有效后恢复 |
| 启动时提示已使用默认配置 | 手改配置、字段类型错误、阈值不合法，或文件被截断 | 修正 TOML 后重启；或恢复备份；不会显示原始堆栈 |
| 扩展突然 401 | 配置损坏后重新生成了桥接令牌 | 恢复备份，或从桌面端重新复制令牌并配对 |
| 配置反复损坏 | 磁盘写入失败、同步工具覆盖，或编辑时应用仍在运行 | 退出应用后再改配置；避免云盘同步正在写的文件；保留最新备份 |

配置保存是原子写入；失败不会覆盖旧文件。恢复配置前先退出应用，避免再次写盘。
